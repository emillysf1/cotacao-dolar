# Cotação do Dólar para 365 Dias

Este projeto contém uma função em Python para consultar a cotação de compra do dólar dos últimos 365 dias, utilizando dados da API oficial do Banco Central do Brasil (PTAX).

---

## 📌 Requisitos da Atividade

- Toda a funcionalidade contida em uma função sem argumentos chamada `cotar`.
- Sequência dinâmica de 365 dias retroativos a partir da data atual de execução.
- Uso exclusivo das bibliotecas `datetime` e `requests`.
- Resposta contida no arquivo `solution.py`.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.x**
- **datetime**: Manipulação e formatação de datas.
- **requests**: Consumo da API REST da PTAX do Banco Central do Brasil.
